# AI Biz Tools — Launch Checklist

## Before production
- Set `NEXT_PUBLIC_SITE_URL` to the final HTTPS domain.
- Run `npm.cmd run build` locally and fix any build errors.
- Test Finder on desktop/mobile.
- Test every Review and vendor link.
- Replace any remaining placeholder domain.
- Verify privacy, terms and affiliate disclosure.

## Analytics
Events already prepared:
- finder_completed
- review_clicked
- vendor_clicked

Connect Google Tag Manager / GA4 after the production domain exists.

## Search
After deployment:
- add the property to Google Search Console;
- submit `/sitemap.xml`;
- inspect the homepage and the five priority SEO URLs;
- monitor indexing, impressions, queries and CTR;
- do not mass-publish thin pages.
